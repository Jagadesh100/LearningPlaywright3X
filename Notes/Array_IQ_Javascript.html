Arrays in JavaScript

1. What is an Array?

An array is a special variable that can store multiple values in one variable.

let fruits = ["apple", "banana", "mango"];

2. Ways to Declare an Array

Array Literal

let numbers = [10, 20, 30];

Using new Array()

let numbers = new Array(10, 20, 30);

Empty Array

let emptyArray = [];

3. Array Declaration Used in Real-Time Projects

Arrays are commonly used for user lists, products, API responses, and form values.

let users = [
  { id: 1, name: "John" },
  { id: 2, name: "Alice" }
];

4. Accessing Array Elements

let fruits = ["apple", "banana", "mango"];
console.log(fruits[0]);
console.log(fruits[2]);

5. Modifying Array Elements

let fruits = ["apple", "banana", "mango"];
fruits[1] = "orange";
console.log(fruits);

6. Common Array Methods

  • push() - add to the end
  • pop() - remove from the end
  • shift() - remove from the beginning
  • unshift() - add to the beginning
  • indexOf() - find index of an element
  • includes() - check if an element exists
  • splice() - add or remove elements
  • slice() - copy a part of the array
  • join() - convert to string

7. Example

let fruits = ["apple", "banana", "mango"];
fruits.push("orange");
console.log(fruits);

8. Quick Summary

Arrays store multiple values, are indexed from 0, and are widely used in real-time web development.
